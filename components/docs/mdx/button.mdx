## Variants

`accent` is the one primary action on a screen: Add this device, Reconnect, Download. `tint` is a quiet primary, like a card's Connect. `soft` is for Cancel, Copy and Start over. `red` is for Remove. Use buttons and pills for actions: never blue text links.

<ComponentPreview
  name="button-variants"
  previewClassName="h-auto min-h-[200px]"
/>

`default` is `accent`, `secondary` is `soft` and `destructive` is `red`, so code written for shadcn/ui keeps working. `outline` and `ghost` are quiet fills without a border; `link` is only for a link inside a sentence.

## Icon

The round buttons are knobs: a 32px circle (`icon`) with a 16px icon. They scale to 0.8 under a press. `icon-lg` is 40px, `icon-sm` 28px and `icon-xs` 24px. Give them an `aria-label`.

## Loading

Pass `loading` while the button waits for an answer. The button keeps its size, its content blurs away and the orb comes up through the blur in the button's own colour. The button stays focusable and ignores clicks meanwhile. It needs no client code: loading is a plain prop, so the button renders on the server too.

## Design

- **Shape.** A pill: 48px high, 20px padding, an 18px icon, 16/22 text at 500 (600 on accent, tint and red) with -0.015em tracking. No ellipsis on a button: "Remove", never "Remove...".
- **Press.** `scale(.95)` on 200ms ease-out (`--ease-out`). Knobs scale to 0.8 on 150ms.
- **Hover.** accent goes to 82%, tint to 20% (24% pressed) and soft to +6% of the text colour (+10% while it holds an open menu). All on 200ms.
- **Busy.** The content goes out in 180ms ease-in (`blur 5px`, `scale .86`). The orb comes in 70ms later over 340ms ease-out and is not drawn at all (its loop is stopped) while the button is not waiting. It is Orbs B4 Converge from aicss.dev: one dot walks a triangle and a second breathes in the middle, 1.8s loops.
- **Focus.** A 2px accent ring at 65%, 2px outside the pill, only while the keyboard moves focus.
- **Reduced motion.** Transitions shorten and the orb loop stops moving.

## API Reference

| Prop | Description |
| --- | --- |
| `variant` | `"accent"` (or `"default"`), `"tint"`, `"soft"` (`"secondary"`), `"red"` (`"destructive"`), `"outline"`, `"ghost"`, `"link"`. |
| `size` | `"default"`, `"sm"`, `"xs"`, `"lg"`, `"icon"`, `"icon-lg"`, `"icon-sm"`, `"icon-xs"`. |
| `loading` | Waiting for an answer. Shows the orb and ignores clicks. Leave it out for a plain button. |
| `render`, `nativeButton` | Draw the button as another element. See [Base UI](https://base-ui.com/react/components/button#api-reference). |
