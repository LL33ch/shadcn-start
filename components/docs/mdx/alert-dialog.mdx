## Usage

```tsx showLineNumbers
import {
  AlertDialog,
  AlertDialogAction,
  AlertDialogCancel,
  AlertDialogContent,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogHeader,
  AlertDialogMedia,
  AlertDialogTitle,
  AlertDialogTrigger,
} from "@/components/ui/alert-dialog"
```

```tsx showLineNumbers
<AlertDialog>
  <AlertDialogTrigger>Remove</AlertDialogTrigger>
  <AlertDialogContent>
    <AlertDialogHeader>
      <AlertDialogMedia>
        <GlassIcon name="trash" tone="red" />
      </AlertDialogMedia>
      <AlertDialogTitle>Remove this device?</AlertDialogTitle>
      <AlertDialogDescription>
        The router will forget its key.
      </AlertDialogDescription>
    </AlertDialogHeader>
    <AlertDialogFooter>
      <AlertDialogCancel>Cancel</AlertDialogCancel>
      <AlertDialogAction variant="red">Remove</AlertDialogAction>
    </AlertDialogFooter>
  </AlertDialogContent>
</AlertDialog>
```

## Tones

The icon says what kind of question it is, and the action button agrees with it. A removal has a `red` glass trash and a `red` action. A step that costs something, like Reconnect, has an `orange` icon and an accent button.

## Design

- **Sheet.** The same as [Dialog](/docs/dialog): `card`, radius 36, padding 24 and the sheet shadow. A drawer on a phone and a dialog popping up from its centre from 760px, with the same timings.
- **Question.** Left-aligned, with 24px at the top. A 64px glass icon, a 20/28 title at 500 and a 15/21 paragraph in the secondary text colour.
- **Buttons.** Two equal buttons in a row, default size. **Cancel** is `soft`. The action is `accent`, or `red` for a removal. There is no × beside them.
- **Has to be answered.** A press on the scrim does not close it. A button or Escape does.
- **Action.** `AlertDialogAction` closes the dialog and runs `onClick`. To keep it open while something runs, control it with `open` and `onOpenChange` and give the button `loading`.

## API Reference

| Part | Description |
| --- | --- |
| `AlertDialog` | The root. Controlled with `open` and `onOpenChange`, or `defaultOpen`. |
| `AlertDialogTrigger` | Opens the dialog. Draw it as a `Button` with `render`. |
| `AlertDialogContent` | The sheet and its scrim. |
| `AlertDialogHeader`, `AlertDialogTitle`, `AlertDialogDescription` | The question. |
| `AlertDialogMedia` | A 64px box for a glass icon. |
| `AlertDialogFooter` | A row of equal buttons. |
| `AlertDialogCancel` | Closes the dialog. A `soft` button by default. |
| `AlertDialogAction` | Closes the dialog. An `accent` button by default; takes the Button's `variant` and `size`. |

See the [Base UI](https://base-ui.com/react/components/alert-dialog#api-reference) documentation for the rest.
